### Controls

**Keyboard**
- `WASD` / Arrow Keys — Move (or drive)
- `E` — Get in / out of a machine
- `SPACE` — Throw dynamite / Swing wrecking ball (fires in the direction you face)
- `F` or Left Click — Melee (khopesh)
- `SHIFT` — Sprint / Bulldozer boost
- `R` — Eye of Horus radar
- `TAB` — Switch between Facing aim and Mouse aim
- `P` / `ESC` — Pause
- `M` / `N` — Toggle music / sound
- `F11` — Fullscreen

**Controller** (any USB / Xbox-style pad)
- Left Stick — Move / Drive
- Right Stick — Aim
- `A` — Fire
- `X` — Melee
- `Y` — Get in / out
- `B` — Eye of Horus
- `RB` — Boost
- `Start` — Pause
- `Back` — Switch aim mode
